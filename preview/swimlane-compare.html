说明

  • 本页作用：泳道图（commit DAG）渲染的离线调试 / 回归测试页 —— 不依赖 DSH 运行时与真实仓库即可预览、调参、留档对比。
  • 数据与算法：样例 DAG 见 MOCK_ROWS（覆盖：未提交改动虚拟行、stash、合并提交、多分支、同名本地/远程 refs、tag）；布局算法 buildGitGraph 与 graphPaths 自 src/client/index.js 逐行移植 —— 改源码算法时请同步本页。
  • 基线面板：固定渲染插件现役参数（SHIPPED，对应源码 GIT_GRID 与 .dsc-gline*/.dsc-gref CSS）；它是回归对照，不随右侧控件变化。
  • 试验台面板：滑块实时改变量并重排；参数自动持久化到 localStorage（刷新不丢）；「恢复默认（= 基线）」清除存档并回到现役值。
  • 复制参数给 AI：把当前试验参数序列化为 JSON 复制到剪贴板（下方输入框同步显示，可手动 Ctrl+C），便于把定稿参数写回插件源码。
  • 接口约定：试验台 offset 由 offsetX = x/2、offsetY = y/2 + 0.5 派生；roundR = 0 即直角折角；roundCap 控制线帽/线结是否圆头。
